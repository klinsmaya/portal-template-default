# 使用说明

自驱战略 · 定三责平台把《自驱战略》书中的三张检查表变成一步一步的在线工作：**定战略责 → 定目标责 → 定行动责**。每一步都有一张成果表，企业填写、咨询师复核、企业确认后定版；下游表格引用上游的定版内容，上游一改，下游会提示“上游已变更”。

入口：`https://<域名>/x/dingze/`，用分配的账号登录（平台不开放自助注册）。

---

## 一、企业成员

### 1. 进入项目

登录后进入“我的项目”，点开项目进入**工作台**：三阶段进度、待办和“上游已变更”的成果都在这里。

项目顶部有六个页签：

| 页签 | 用途 |
|---|---|
| 工作台 | 项目概览、待办 |
| 咨询工作区 | 逐表填写成果（主要工作区域） |
| 资料与画像 | 上传企业资料、维护企业画像（见第 7 节） |
| 成果与定版 | 全部成果的状态、版本、操作记录和版本差异 |
| 交付 | 导出正式交付物、各部门绩效计分卡、导出记录 |
| 专家咨询 | 申请人工专家咨询（见第 8 节） |

### 2. 在咨询工作区填写成果

- 左侧是步骤条，按书的顺序排列。前一步“本步完成”后，后一步才解锁；上一阶段 P0 成果全部定版后，下一阶段才开启。
- 中间是成果表。很多表有“带入 / 导入”按钮，可以从上游表直接带入，不用重抄。
- 下方的校验条会列出必须改的问题（红色）和建议（黄色）。红色问题没改完，不能点“本步完成”。**点问题可直接跳到对应的行或格**（会切换页签、展开折叠并闪烁提示）。
- 右侧是**数字咨询师**：可以就当前这张表提问，让它出修改建议。建议以卡片形式给出，**点“确认写入”才会改动成果**。
- 改完记得点“保存”（或按 Ctrl / ⌘ + S）。每次保存都会生成一个新版本；有未保存的修改时切换页面会先提醒。
- 改错了可以**撤销 / 重做**（工具栏按钮，或 Ctrl / ⌘ + Z、Ctrl / ⌘ + Shift + Z）；连续输入会合并成一步，最多保留 100 步，保存后仍可撤销到保存前的草稿。
- 右侧切到**批注**页签，可以对整张表或某一行 / 某个格留言（光标所在的行会自动带入），可 @ 项目成员、回复、标记解决。有未解决批注的行左侧有金色竖线，步骤条上显示未解决数；被 @ 或批注有回复时会收到通知，点通知直达该条批注。只读成员只能查看。
- 右侧“书中方法”列出这张表在书里的要点、常见的坑和定版门禁；RACI 表下方还有书中表 3-18 的验证优化表，实时检查无 R / 无 A / 多 C / 多 I 等问题。

### 3. 本步完成 → 复核 → 确认

1. 企业填写完毕，由企业项目负责人或部门负责人点 **本步完成**。
2. 咨询师、企业项目负责人或部门负责人**提交复核**，主咨询师**复核通过**或**退回修改**（退回必须写原因）。
3. 复核通过后，**企业项目负责人**点 **确认**，成果**定版**。定版后只读，如需修改，由主咨询师“解锁重开”。

> 只有企业项目负责人可以确认定版；企业管理员身份本身不带确认权。

不同意但愿意执行的意见，可以在成果下方“团队异议（反对但承诺执行）”里记录。

### 4. 年度经营计划书

定行动责的最后两张是公司级和部门级年度经营计划书。“企业录入”的章节由企业填写；“同源 · 自动汇总”的章节直接引用已定版的成果，不需要也不能重写。

公司级计划书确认时，它引用的《项目任务书》《计划实施推进表》《项目资源匹配表》必须已复核通过，确认后四张表**一起定版**。

### 5. 导出

- 成果页右上角“导出 Excel / 导出 Word”导出最近一次**保存**的版本。
- S1-01（战略屋 / 六分法）和 S1-02（战略地图）还有“导出图片”：PNG 适合汇报和文档，SVG 是矢量图，可再编辑。
- 公司级年度经营计划书第一章自动附图 1-1 战略屋（或六分法表）和图 1-2 战略地图，Word 中为矢量图（老版本 Word 显示清晰位图）。
- “交付”页导出的是**定版版本**；尚未定版的导出文件会标“草稿”。
- 所有导出都记录在“交付 → 导出记录”。

### 6. 通知

右上角铃铛显示站内通知：待复核、待确认、退回、定版、重开、上游已变更、加入项目、批注与 @、专家咨询进展。点通知直达对应成果、批注或咨询。

### 7. 资料与企业画像

- **资料库**：上传经营总结、行业报告等（Word、PDF、Excel、txt / md / csv，单个不超过 20MB），平台在浏览器里提取文字后保存；也可以直接粘贴文字。数字咨询师会检索资料并注明出处。
- **企业画像**：按“事实 / 假设 / 未知 / 待补”分类记录企业情况，每条注明来源。可以让数字咨询师根据资料起草画像条目（需确认写入，起草的条目一律为草稿）。
- 画像条目由咨询师**复核**、企业项目负责人**确认**；他人修改已复核或已确认的条目，会回到草稿。两人同时编辑时，后保存的一方会被提示刷新。
- 画像摘要会随页面上下文提供给各阶段的数字咨询师。

### 8. 专家咨询

遇到方法流程解决不了的关键分歧（战略取舍、路径合理性、责任冲突、资源约束），在项目的“专家咨询”页**申请专家咨询**：写清议题和问题，并勾选要授权专家查阅的**已定版成果**（以申请时的定版为准）。

流程：咨询管理员受理并分派专家 → 专家预约沟通时间与方式 → 专家写纪要和意见 → 申请人或企业项目负责人确认关闭。出意见前申请人可以撤回。每一步都会通知相关人。年度经营计划质询在线下进行，不在平台内申请。

## 二、咨询师

- 登录后进入**咨询师工作台**：跨企业汇总待复核、待提交复核、待企业确认、上游已变更和待跟进的成果，可按企业和阶段筛选。
- 复核：打开成果 → 查看校验结果和“成果与定版 → 历史 → 版本对比” → 复核通过或退回（写原因）。
- 解锁重开：已定版成果需要修改时，由主咨询师“解锁重开”并写明原因；下游表格会标“上游已变更”，企业核对后保存一次即可消除。重开后未改动又定版，下游提示会自动消失。
- 开例外：确有需要跳过解锁顺序时，主咨询师可为某一步“开例外”，操作会写入审计记录。
- **成果与定版**页的“AI 初稿 → 定版”一列，显示数字咨询师给出的最后一版初稿与最终定版之间的差异，用于方法和规则改进。
- **记录引导缺口**：发现数字咨询师没引导到、引导错了，或校验口径与书不符时，在工作区右侧数字咨询师下方点“记录引导缺口”，写明缺口与期望的引导（对话摘录请去掉企业敏感信息）。评审结果会通知你。
- **企业画像**：在“资料与画像”页复核画像条目。
- **专家咨询**：被分派为专家时会收到通知；在侧栏“专家咨询”打开申请，查阅授权的定版成果，预约沟通、填写纪要和意见。

## 三、运营管理员 / 咨询管理员

侧栏“运营管理”：

| 页面 | 用途 |
|---|---|
| 运营看板（默认页） | 各企业项目的阶段进度（P0 定版数）、待复核 / 待确认 / 待更新 / 未解决批注积压、数字咨询师近 30 天与累计的对话轮次和 Token 用量（只记录不计费），可按企业和“只看有待办”筛选 |
| 企业与开通 | 开通企业（自动建空间和企业管理员账号）、停用 / 启用企业、维护企业成员和组织部门、新建项目、分派项目成员与项目角色 |
| 咨询团队 | 创建咨询师、咨询管理员、运营管理员账号，重置密码 |
| 方法与规则包 | “规则包”页签：成果目录与数字咨询师（只读）；“引导缺口”页签：评审咨询师记录的缺口——采纳 / 不采纳（须写理由）→ 改写规则并随新版插件发布后标“已发布”（填版本号），每次评审通知记录人 |

侧栏“专家咨询”：受理新申请并分派本企业空间里的咨询师为专家（咨询师需先是该企业成员），可改派；也可代为预约和填写意见。

要点：

- 一个企业对应一个独立空间，企业之间的项目、成果、通知、导出互不可见。
- 停用企业后，该企业成员立即无法打开项目（运营与咨询管理员仍可查看）。
- 新账号的初始密码只在创建时显示一次，请通过安全渠道转交，并提醒首次登录后修改。
- 企业管理员可在“本企业”里维护本企业成员和组织部门。

## 四、角色速查

| 项目角色 | 能做什么 |
|---|---|
| 企业项目负责人 | 填写、本步完成、提交复核、确认定版、待确认时退回 |
| 部门负责人 | 填写、本步完成、提交复核 |
| 项目成员 | 填写 |
| 只读成员 | 查看 |
| 主咨询师 | 修订、提交复核、复核通过 / 退回、解锁重开、开例外 |
| 协作咨询师 | 修订、提交复核 |
| 咨询管理员（系统角色） | 解锁重开、开例外、强制定版、强制退回（均需写原因）；受理专家咨询、评审引导缺口 |
| 运营管理员（系统角色） | 运营管理全部页面，含运营看板、引导缺口评审、专家咨询受理 |

画像条目：咨询师复核、企业项目负责人确认。批注：除只读成员外都可发表；作者、企业项目负责人、主咨询师可标记解决。
